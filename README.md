# Solução / Meta entregue na primeira entrega:

## Landing page com botões “Área do Professor” e “Área do Aluno”;

## A área do professor contará com dois botões:

### Solicitar um novo roteiro: após colocar e-mail institucional e nome, pode passar as informações para a equipe encaminhar para a inteligência artificial, as informações são enviadas através de uma API que envia via e-mail (EmailJS ou Resend)

### Publicar Roteiro: o professor receberá no e-mail um roteiro em formato PDF. Ele pode publicar o roteiro e adicionar uma sessão externa com link e texto de um site que preferir.

## A área do aluno terá um filtro para identificar a matéria e ano que ele deseja visualizar;

## Após o filtro, os roteiros são disponibilizados em forma de lista, onde os alunos podem interagir e consultar. Junto com os roteiros, poderá haver um texto de apoio externo disponibilizado pelo professor.

## O roteiro terá um header com título, tema e descrição. Abaixo, questões e explicações curtas. Deverá identificar que é feito por IA.
